EasyOCR is a planned project for deploying an OCR workflow on a server or local machine. The goal is to upload PDFs or other document formats and receive a Markdown folder that preserves images, layout structure, text, and formulas.

Later, this project can be packaged as an agent skill so an agent can automatically upload PDFs, run OCR, and download the generated Markdown folder for downstream reading, retrieval, and storage.
